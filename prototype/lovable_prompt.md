# Build the clickable prototype yourself (Lovable or similar)

Paste into Lovable, iterate, then publish and link it from the README. Only list Lovable on your resume for this project
**after** you have actually built and iterated on the prototype yourself.

```
Build a desktop web prototype (React + Tailwind + Recharts) of "Demand Insights", a B2B data product. Mock data only.
Pages: Dashboard (category/region/period filters, line chart of an enquiry index, KPI card, top movers list, privacy notice),
Category detail (regional table where one region shows "n/a (suppressed)"), API (keys table, usage bar 4,120/10,000, curl quick start),
Methodology (static text). Add a "Request API access" button that opens a modal and stores the email in local state only.
Use the sample data in category_demand_trends.csv (paste 20 rows). Clean, analytical, light theme.
Footer: "Prototype for a product case study. Synthetic data."
```
